# GL-kun — グループリーダー向け自動レビューシステム

PMBOK・Terasoluna・プロジェクト規約・課題情報に基づき、設計書や試験項目書を
自動レビューする Web アプリケーションです。

## 機能

| 機能 | 説明 |
|------|------|
| **基本設計書レビュー** | PMBOK・Terasoluna準拠、フォーマット、プロジェクト規約の観点でレビュー |
| **試験項目書レビュー** | 網羅性・手順の具体性・判定基準の明確さなどをチェック |
| **試験結果報告書レビュー** | 品質評価・リリース判定の妥当性をチェック |
| **プロジェクトコンテキスト設定** | プロジェクト概要・固有ルール・最近の課題を事前登録 |
| **ストリーミング出力** | レビュー結果をリアルタイムで表示 |
| **プロンプトキャッシュ** | PMBOK/Terasolunaガイドラインをキャッシュしてコスト削減 |

## レビュー観点

- **PMBOK** — スコープ・品質・リスク・コミュニケーション管理
- **Terasoluna** — レイヤードアーキテクチャ・MyBatis・セキュリティ・テスト設計
- **ドキュメントフォーマット** — 必須記載項目・品質チェックリスト
- **プロジェクト固有ルール** — 事前設定した規約に基づく確認
- **課題/障害情報** — 登録した課題・教訓に基づく重点確認

## セットアップ

```bash
cd backend
cp .env.example .env
# .env に ANTHROPIC_API_KEY を設定

pip install -r requirements.txt
python main.py
```

ブラウザで `http://localhost:8000` を開きます。

## 使い方

### 1. プロジェクト設定（初回のみ）
「プロジェクト設定」タブで以下を登録：
- プロジェクト概要（システム名・技術スタック・体制）
- プロジェクト固有ルール（命名規則・設計ルールなど）
- 最近の課題・障害（過去の不具合・教訓）
- 追加チェックリスト（プロジェクト固有の確認事項）

### 2. レビュー実行
「レビュー実行」タブで：
1. ドキュメント種別を選択（基本設計書 / 試験項目書 / 試験結果報告書）
2. ドキュメント本文を貼り付け
3. 「レビュー開始」ボタンをクリック

レビュー結果が以下の形式でリアルタイム表示されます：
1. **総合評価**（A/B/C/D）
2. **観点別レビュー**（PMBOK・Terasoluna・フォーマット・プロジェクト）
3. **重要指摘事項**（必須対応項目）
4. **改善提案**
5. **総評**

## アーキテクチャ

```
GL-kun/
├── backend/
│   ├── main.py          # FastAPI エンドポイント
│   ├── reviewer.py      # Claude API レビューエンジン（プロンプトキャッシュ・ストリーミング）
│   ├── prompts/
│   │   ├── pmbok.md         # PMBOK レビューガイドライン
│   │   ├── terasoluna.md    # Terasoluna レビューガイドライン
│   │   └── doc_formats.md   # ドキュメントフォーマット規定
│   └── requirements.txt
├── frontend/
│   ├── index.html       # SPA
│   ├── style.css
│   └── app.js           # ストリーミング受信・Markdown レンダリング
└── data/
    └── context.json     # プロジェクトコンテキスト（gitignore済み）
```

## 技術スタック

- **バックエンド**: Python / FastAPI / Anthropic SDK
- **AI モデル**: Claude Opus 4.8（adaptive thinking + prompt caching）
- **フロントエンド**: HTML / CSS / Vanilla JS（依存ライブラリなし）

## カスタマイズ

### レビューガイドラインの拡張
`backend/prompts/` 配下のMarkdownファイルを編集することで、
レビュー観点を自由に追加・変更できます。

### モデル・パラメータ変更
`backend/reviewer.py` の `stream_review()` 関数内でモデルや
`max_tokens` などのパラメータを調整できます。
